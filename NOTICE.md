# Credits

ZEDP-RTL is an independent Windows build of [Zed](https://github.com/zed-industries/zed).
The RTL work builds on [AmirAliManzar/Zed-RTL](https://github.com/AmirAliManzar/Zed-RTL/tree/f67c7f3c147b658d4aaed9e6759817e53901b2e3).
The Windows port uses DirectWrite's native visual positions and carries changes for text selection, line splitting, application identity and update notifications.

The project is distributed under GPL-3.0. The upstream GPUI crates retain their Apache-2.0 license. Bundled console and graphics runtime files come from the corresponding official Zed Windows release and retain their original licenses.
