# ZEDP-RTL

نسخهٔ ویندوز x64 از Zed با پشتیبانی از نمایش و انتخاب متن فارسی کنار کد انگلیسی. نسخهٔ پایه در [upstream.json](upstream.json) ثبت شده است.

## نصب و اجرا

فایل `ZEDP-RTL-<version>-x64.exe` را از پوشهٔ `dist` اجرا کنید. بعد از نصب، برنامه با نام **ZEDP-RTL** در Start دیده می‌شود. ویندوز این نسخه را مستقل ثبت می‌کند و می‌توانید آن را از Installed apps حذف کنید.

برای باز کردن پروژه از PowerShell این دستور را اجرا کنید.

```powershell
& "$env:LOCALAPPDATA\Programs\ZEDP-RTL\bin\zedp.exe" .
```

پروفایل معمول این برنامه در `%APPDATA%\ZEDP-RTL` و `%LOCALAPPDATA%\ZEDP-RTL` است. همین پوشه‌های جدا و شناسهٔ اختصاصی برنامه اجازه می‌دهند دو نسخه هم‌زمان باز باشند. نصب اولیه یک پروفایل تازه می‌سازد.

## ساخت محلی

PowerShell 7، Git، rustup، ابزارهای MSVC x64 با کتابخانه‌های Spectre، Windows SDK، CMake و کامپایلر Inno Setup لازم‌اند. از پوشهٔ پروژه این دستور را اجرا کنید.

```powershell
.\build.ps1
```

اسکریپت نسخهٔ مشخص‌شده از Zed را می‌گیرد، پچ را اعمال می‌کند، ادیتور و CLI را می‌سازد و تست‌های نشانگر و DirectWrite را اجرا می‌کند. نصاب، SHA-256 و سورس همان بیلد در `dist` قرار می‌گیرند. برای تعیین مسیر کامپایلر از `-Iscc 'C:\Tools\Inno Setup\ISCC.exe'` استفاده کنید.

## همگام‌سازی

پس از انتشار این پروژه در یک مخزن GitHub با Actions فعال، [گردش کار انتشار](.github/workflows/stable.yml) هر چهار ساعت آخرین انتشار پایدار Zed را بررسی می‌کند. برای هر نسخه، اولین بیلد موفق که تست‌ها را گذرانده باشد، نصاب و سورس متناظر را منتشر می‌کند. اگر پچ با سورس جدید ناسازگار باشد، اجرای Actions در همان مرحله متوقف می‌شود و دلیل را در لاگ ثبت می‌کند.

بیلدهای منتشرشده نام مخزن خودشان را هنگام کامپایل دریافت می‌کنند. وقتی گزینهٔ آپدیت فعال باشد، ادیتور انتشار جدید آن مخزن را بررسی می‌کند و یک دکمه برای باز کردن صفحهٔ دانلود نشان می‌دهد. برای تعیین مخزن در بیلد محلی، دستور زیر را با نام واقعی مخزن اجرا کنید.

```powershell
.\build.ps1 -ReleaseRepository 'OWNER/ZEDP-RTL'
```

برای امتحان کردن پچ روی نسخهٔ پایدار بعدی، Tag واقعی آن نسخه را به `-Tag` بدهید. `-PrepareOnly` فقط سورس را آماده می‌کند. اگر تغییری در موتور متن با پچ تعارض داشته باشد، پچ [patches/zedp-rtl.patch](patches/zedp-rtl.patch) باید با آن تغییر سازگار شود. تست ویندوز موقعیت انتخاب و نشانگر را با خروجی خود DirectWrite مقایسه می‌کند.

منبع اصلاح اولیهٔ RTL و مجوزها در [NOTICE.md](NOTICE.md) آمده‌اند.
